📚 RUANG BELAJAR

Jelajahi Materi SPLDV

Pelajari setiap konsep sebelum menghadapi tantangan.

📘

1. Pengertian SPLDV

Sistem Persamaan Linear Dua Variabel (SPLDV) adalah sistem yang terdiri atas dua persamaan linear dengan dua variabel yang sama.

a₁x + b₁y = c₁
a₂x + b₂y = c₂
🔍

2. Unsur SPLDV

SPLDV memiliki variabel, koefisien, dan konstanta. Variabel merupakan nilai yang belum diketahui, koefisien merupakan bilangan pengali variabel, sedangkan konstanta merupakan bilangan tetap.

Contoh: 3x + 2y = 12. Variabelnya x dan y, koefisiennya 3 dan 2, serta konstantanya 12.
📊

3. Metode Grafik

Metode grafik dilakukan dengan menggambarkan kedua persamaan pada bidang koordinat. Titik potong kedua garis merupakan solusi SPLDV.

🔄

4. Metode Substitusi

Metode substitusi dilakukan dengan menyatakan satu variabel dalam bentuk variabel lainnya, kemudian menggantikannya ke persamaan kedua.

x + y = 7, jika x = 3, maka y = 7 - 3 = 4.
➖

5. Metode Eliminasi

Metode eliminasi dilakukan dengan menghilangkan salah satu variabel menggunakan operasi penjumlahan atau pengurangan.

2x + y = 11
x + y = 7
Dikurangkan menghasilkan x = 4.
🧩

6. Metode Gabungan

Metode gabungan merupakan kombinasi metode eliminasi dan substitusi untuk mendapatkan nilai kedua variabel.

🛒

7. Penerapan SPLDV

SPLDV dapat digunakan untuk menyelesaikan masalah sehari-hari, misalnya menentukan harga barang, umur, dan jumlah benda.
